## 0. 先选一个版本

LongPost 有两条产品线，功能不完全一样，先对照下表选：

| 你想做什么 | 用哪个 |
| :--- | :--- |
| 发布文章、被搜索到、和读者互动 | **Web 版**（自建或访问部署好的站点） |
| 在自己电脑上安静写作、数据只存本机 | **桌面版**（Windows / macOS / Linux） |
| 手机上随时记、随时看 | **安卓版**（APK） |

功能覆盖对照：

| 能力 | Web | 桌面 | 安卓 |
| :--- | :---: | :---: | :---: |
| Markdown 编辑器 / 实时预览 | ✅ | ✅ | ✅ |
| 交互式图表 / Mermaid / 公式 | ✅ | ✅ | ✅ |
| AI 写作助手 | ✅ | ✅ | ✅ |
| 导出 HTML / MD / PDF / EPUB / 长图 | ✅ | ✅ | ✅ |
| WebDAV 跨端同步 | ✅ | ❌ | ❌ |
| 应用内更新 | — | ✅ | ❌ |
| 社区（点赞 / 评论 / 关注 / 私信） | ✅ | ❌ | ❌ |
| 视频会议 | ✅ | ❌ | ❌ |

> 桌面与安卓是**纯本地**写作台：没有账号、不联网也能用，只有 AI、更新检查会出站。

## 1. 安装

### 1.1 Windows
下载 `LongPost.Setup.2.9.9.exe`（安装版）或 `LongPost.2.9.9.exe`（免安装便携版，双击即用）。

首次运行若被 SmartScreen 拦下，点「更多信息 → 仍要运行」。

### 1.2 macOS
下载 `LongPost-2.9.9-arm64.dmg`，拖进「应用程序」。因为还没有代码签名，首次打开需要**右键 →「打开」**放行一次。

### 1.3 Linux
下载 `LongPost-2.9.9.AppImage`：

```bash
chmod +x LongPost-2.9.9.AppImage
./LongPost-2.9.9.AppImage
```

### 1.4 安卓
下载 `LongPost-v2.9.9-android.apk` 直接安装。注意是 **debug 签名**，换版本时需要先卸载旧版。

### 1.5 Web（自建）
见本文第 9 节「自建部署」。

## 2. 第一次打开（桌面 / 安卓）

1. 点左上角 **「新建文章」**，中间出现编辑器，右边是实时预览；
2. 顶部输入标题，正文直接写 Markdown；
3. 左下角状态栏显示字数、保存状态；
4. 数据默认存在本机（桌面：用户目录下的 JSON；安卓：IndexedDB），可在「设置 → 数据与关于」看到完整路径。

### 2.1 本地空间（可选）

写作台支持把文章分到互相隔离的「空间」，适合和家人/同事共用一台设备：

- 左下角 **「登录 / 切换空间」** → 输入**通行码**，或用 **Google 邮箱 + 至少 4 位安全口令**；
- 每个空间的文章完全隔离，看不到彼此；
- 口令用于派生本地加密密钥，**忘了就打不开**，请自行保管。

## 3. 写作

### 3.1 界面

```
┌──────────┬───────────────────────┬──────────────────┐
│ 文章列表 │  标题 + 格式工具条     │                  │
│ 搜索     │  编辑区（Markdown）   │  实时预览         │
│ 标签筛选 │                       │（图表 / 公式 / 图）│
└──────────┴───────────────────────┴──────────────────┘
```

- 拖中间的竖线可调分栏宽度；
- 窄屏（手机）顶部有「写作 / 对照 / 预览」三态切换；
- 右上角一排图标：大纲、统计、长图、附件、分享、全屏、偏好、搜索。

### 3.2 常用快捷键

| 快捷键 | 作用 |
| :--- | :--- |
| `Ctrl/Cmd + S` | 立即保存（关闭自动保存时唯一落盘方式） |
| `Ctrl/Cmd + B` | 加粗 |
| `Ctrl/Cmd + F` | 查找替换 |
| `Ctrl/Cmd + K` | 全局指令面板（Web 端） |
| `Ctrl/Cmd + /` | 快捷键与语法指南（Web 端） |
| `Alt + M` | 切换极简版 / 专业版工作区 |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进 |
| `Enter` | 自动续写列表项 |
| 输入 `/` | 呼出斜杠指令菜单 |

### 3.3 Markdown 速查

```markdown
# 一级标题        ## 二级        ### 三级
**加粗**  *斜体*  ~~删除线~~  ==高亮==  `行内代码`
- 无序列表        1. 有序列表      - [ ] 待办
> 引用            ---  分割线
[链接](https://example.com)   ![图片](url)
| 表头 | 表头 |
| --- | ---: |
代码块：三个反引号包裹，开头可加语言名（如 typescript）自动高亮
$$ E = mc^2 $$    独立公式
```

### 3.4 交互式图表

用 `chart` 围栏写一段 JSON，正文里就会出现可交互图表（不是截图）：

````markdown
```chart
{
  "type": "bar",
  "title": "每月发布篇数",
  "xAxis": ["3月", "4月", "5月", "6月"],
  "series": [{ "name": "发布", "data": [4, 7, 5, 9] }]
}
```
````

支持 `bar` / `line` / `area` / `pie`，可选 `height`。导出的 HTML 里图表同样可交互。

### 3.5 专业版专属工具

切到**专业版**（`Alt + M`）后，工具条会多出四个本地工具：

| 工具 | 作用 |
| :--- | :--- |
| 知识图谱 | 扫描全库标签与引用关系，力导向图，点节点可跳转 |
| 写作实验室 | 字数/词频透视 + 5 项排版自检（标题跨级、代码块未闭合、冗余空行、超长段落、图片缺 Alt） |
| 版本差分 | 与历史版本逐行对比，增删高亮，可一键回滚 |
| 灵感白板 | Canvas 手绘，一键转图插入正文 |

## 4. AI 写作助手

### 4.1 怎么用

1. 在正文里**选中至少 2 个字**；
2. 浮出工具条，选一个动作：

| 动作 | 做什么 |
| :--- | :--- |
| **润色** | 提升文采与逻辑，保留原事实 |
| **精简** | 删冗词，留主干 |
| **排版** | 中英文/数字加空格，规范标点，修正语病 |
| **续写** | 按上文语境续 1–2 段 |

3. 结果**流式**逐字出现，随时可点「停止」；
4. 满意就点「替换选中」（续写是「插入到下方」），不满意点「丢弃」。

中文输入法拼写过程中不会误触发。

### 4.2 三种取用方式（自动按优先级选）

| 方式 | 怎么来 | 谁付费 | 适用 |
| :--- | :--- | :--- | :--- |
| ① 本机 Key | 自己填在设置里，只存本机 | 你 | 桌面/安卓主力；不想把 Key 交给服务端 |
| ② 账号托管 | 填一次，加密存进账号，换设备登录即用 | 你 | 多设备切换（仅 Web） |
| ③ 站点额度 | 站长在服务端配好，登录即可用，按天限次 | 站长 | 新用户先试用（仅 Web） |

### 4.3 配置

**桌面 / 安卓**：设置 → 「AI 助手」卡片

- 服务商：OpenAI 兼容 / Gemini / Ollama
- 服务地址、模型名、API Key
- 点「测试连接」验证

常用填法：

| 服务商 | 地址 | 模型示例 | Key |
| :--- | :--- | :--- | :--- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 需要 |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 需要 |
| Gemini | `https://generativelanguage.googleapis.com` | `gemini-2.5-flash` | 需要 |
| 本机 Ollama | `http://127.0.0.1:11434` | `qwen2.5:7b` | 留空 |

> Ollama 需要先在终端跑 `ollama serve`，并允许跨域：启动前设 `OLLAMA_ORIGINS="*"`。

**Web 端**：编辑器里选中文字 → 工具条右侧齿轮 → 填写；面板底部还有「账号托管 / 站点额度」区块，可一键把当前 Key 加密托管到账号。

### 4.4 常见错误

| 提示 | 原因 | 处理 |
| :--- | :--- | :--- |
| 还没有配置 AI | 没填 Key 且未登录 | 设置里填 Key，或登录使用站点额度 |
| HTTP 401 | Key 错误或过期 | 重新生成 Key |
| HTTP 429 | 站点额度用尽 | 等次日，或填自己的 Key |
| 无法连接 | 地址写错 / 被墙 | 检查 Base URL，Ollama 注意端口 |
| 内容过长 | 单次超 6 万字符 | 分段处理 |

## 5. 导出与分享

### 5.1 导出格式

| 格式 | 用途 | 特点 |
| :--- | :--- | :--- |
| **自包含 HTML** | 发给别人双击就能看 | 单文件，图片内联，图表可交互 |
| **分享长图 (.png)** | 发朋友圈 / 聊天窗口 | 2 倍图，按正文全高渲染 |
| **微信公众号排版** | 粘贴到公众号后台 | 复制即带内联样式，粘贴即成文 |
| **Obsidian 笔记 (.md)** | 进第二大脑 | 带 YAML frontmatter 与标签 |
| **标准 Markdown (.md)** | 备份 / 迁移 | 纯文本 |
| **EPUB** | 电子书阅读器 | EPUB 3.0，图片打包 |
| **PDF** | 打印 / 归档 | 学术排版，公式与图表渲染 |

### 5.2 分享（Web）
长文详情页有分享菜单：复制链接、微信 / QQ / 微博 / 空间 / 钉钉、系统分享，以及**直达二维码**。

免登录短链形如 `https://你的域名/p/abc12345`，外部访客无需注册即可阅读全文。

## 6. 同步与备份（WebDAV）

> 目前**仅 Web 端**提供同步界面（编辑器工具栏 →「同步」）。

### 6.1 配置
填 WebDAV 地址、账号、密码（坚果云、Nextcloud、群晖、自建 Apache 均可），先点「测试连通性」。

远程目录约定：

```
/LongPost/manifest.json          同步清单
/LongPost/notes/<id>.json        每篇文章
/LongPost/longpost-backup.json   全量备份
```

### 6.2 同步规则

- **三向合并**：本地最新 vs 远端最新 vs 上次同步快照；
- **墓碑删除**：删了的文章不会因为旧设备上线而复活；
- **冲突保护**：两端都改过时，**绝不静默覆盖**，而是把本地版本另存为「原标题（冲突备份-设备名-时间）」，再拉远端版本；
- **全量备份**：把全库打成单个 JSON 上传；
- **从备份恢复**：合并式，**本地已有的文章不会被覆盖**。

### 6.3 建议
- 首次同步前先「全量备份」；
- 换设备时先在新设备「从备份恢复」，再开启同步；
- 密码建议用应用专用密码，不要用主账号密码。

按 `Alt + M` 或点侧栏模式按钮切换，两套布局与视觉是独立骨架，不只是换色：

| 维度 | 极简版 | 专业版 |
| :--- | :--- | :--- |

| 导航 | 底部悬浮 Dock | 顶部工具带 + 浮动主按钮 |
| 排版 | 首字下沉、标点挤压 | 等宽严谨、结构化 |
| 附加工具 | 沉浸心流 | 知识图谱、写作实验室、差分、白板 |

偏好会记住，下次打开仍是上次的模式。

- **注册/登录**：邮箱密码，或 Google 账号（需站长配置 OAuth）

## 9. 自建部署

### 9.1 最小步骤（Docker Compose）

```bash
cp .env.example .env
echo "POSTGRES_PASSWORD=$(openssl rand -hex 16)" >> .env
# 编辑 .env：填 JWT_SECRET、OWNER_EMAIL

docker compose up -d --build
docker compose logs -f app
```

访问 `http://localhost:3000`。

### 9.2 必填环境变量

| 变量 | 说明 |
| :--- | :--- |
| `JWT_SECRET` | 不填会用默认值，等于谁都能伪造登录态 |
| `OWNER_EMAIL` | 站长邮箱，不填会创建 `admin@longpost.com / admin123` |
| `DATABASE_URL` | PostgreSQL 连接串（compose 里自动拼） |
| `UPLOAD_DIR` | 上传目录，**必须是持久化卷** |

### 9.3 可选：AI 公共额度

```ini
AI_SITE_PROVIDER=gemini
AI_SITE_KEY=AIza...
AI_SITE_MODEL=gemini-2.5-flash
AI_DAILY_QUOTA=20          # 每人每天次数，0 = 关闭
AI_KEY_SECRET=             # 加密用户托管 Key，留空回退 JWT_SECRET
```

### 9.4 PM2 方式

```bash
npm i -g pm2
npm ci --legacy-peer-deps && npm run build
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup
```

> **必须单实例**：没有 Redis adapter 时，多实例会让私信与会议信令的房间广播割裂。

### 9.5 反向代理
参考 [README 的 Nginx 片段](../README.md#-部署web-端)，注意放行 Socket.IO 的 `Upgrade` 头。

### 9.6 备份
```bash
docker compose exec db pg_dump -U longpost longpost > backup-$(date +%F).sql
docker run --rm -v longpost_uploads:/data -v "$PWD":/backup alpine tar czf /backup/uploads.tar.gz -C /data .
```

## 10. 排错

| 现象 | 可能原因 | 处理 |
| :--- | :--- | :--- |
| 桌面版打不开 | 缺少依赖 / 杀毒拦截 | 用便携版试；查看安装目录日志 |
| 数据不见了 | 换了用户 / 数据目录被清 | 设置里看「数据保存在」路径；从 WebDAV 备份恢复 |
| 图表不显示 | JSON 写错 / 类型不支持 | 检查围栏内容；非法图表会降级为代码块显示 |
| 中文输入乱跳 | 输入法合成事件 | 已在划词工具条处理；若仍异常请反馈 |
| 同步冲突频繁 | 多设备同时编辑同一篇 | 正常保护行为；从「冲突备份」文章里合并 |
| 更新检查失败 | 网络不可达 GitHub | 设置里可指定自定义清单地址 |
| Web 登录后 401 | token 过期 | 重新登录 |

日志位置：桌面版安装目录下的 `logs/`；Web 端由 `LOG_DIR` 指定。
