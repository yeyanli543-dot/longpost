# LongPost 剪藏扩展

把网页正文或选中文字一键保存到本机 LongPost 写作台。

## 安装（开发者模式）

1. Chrome 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录

## 配对

1. 打开 LongPost 桌面版 → 设置 → **Chrome 剪藏** → 打开开关
2. 点「复制配对码」（形如 `lp1:52341:9f2c...`）
3. 在扩展的「选项」里粘贴配对码并保存

## 使用

- 右键页面 →「保存到 LongPost」
- 选中文字后右键 →「保存选区到 LongPost」
- 点工具栏图标 →「保存整页」

## 安全说明

- 扩展只访问 `http://127.0.0.1`，不连接任何外部服务器
- 配对码里含令牌，等同密码，不要分享或同步到公共设备
- LongPost 桌面版关闭或没开本地桥时，保存会失败并在通知里说明

## 排错

| 现象 | 处理 |
| --- | --- |
| 通知「还没配对」 | 在扩展选项里粘贴配对码（设置 → Chrome 剪藏 → 复制配对码） |
| 通知「连不上 LongPost」 | 桌面端没开，或本地桥被关掉了 |
| 只保存到几十个字 | 页面是 canvas 渲染（谷歌文档/在线 PPT），改用「从剪贴板保存」 |
| 保存成功但内容是导航栏 | 用「保存选区」，或换用文章详情页再存 |
| 改了设置不生效 | `chrome://extensions` 里点扩展的刷新按钮 |
